# Julieta Gonzalez — Portfolio

Personal portfolio landing page for a Product Manager working in ESG and climate software. Static HTML/CSS, no build step, no client-side state.

## Structure

- `index.html` — page markup
- `css/styles.css` — all styling (design tokens as CSS custom properties in `:root`)
- `assets/` — screenshots used in the "Selected work" section

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Published via GitHub Pages from the `main` branch.
